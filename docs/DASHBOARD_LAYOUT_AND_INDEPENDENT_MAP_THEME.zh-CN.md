# 顶部对齐、竖列指示灯与独立地图日夜模式

2026-10-14。本轮修改继续基于 79be86f 后的地图渐隐、无框指示灯工作区，尚未提交新修改。

## 布局

顶部按视觉高度、中心及线宽对齐，扩大间距；READY 放在车辆蓝牙右边，右转向灯放在时间右边，移除车辆数据演示标记。保留接口的 demonstration 标志，实际数据仍是演示值。

顶部从左到右：左转向、远光、近光、位置灯、车辆蓝牙、READY、手机蓝牙、GPS、蜂窝网络、时间、右转向。

左侧不缩小原图案，优先在第一竖列由上至下排列，满后再在第二竖列由上至下排列；2:1 布局第一列八项、第二列两项，较矮手机默认区域可能第一列七项、第二列三项。维修模式从显示列表移除，状态枚举仍保留兼容未来数据适配。

十项顺序：故障、能量回收、侧撑、座桶、ABS、骑手未就座、缓降、巡航、牵引力控制、充电。

TC 改为汽车正面与打滑线；能量回收改为汽车与循环箭头；巡航改为带刻度、指针和箭头的速度表。自主 Canvas 绘制汽车风格，未宣称其为国标认证图案，未更改原字段及触发极性。参考：[大众巡航图示](https://www.volkswagen.co.uk/en/owners-and-services/my-car/warning-light/cruise-control.html)、[大众 ESC/TCS 图示](https://www.volkswagen.co.uk/en/owners-and-services/my-car/warning-light/electric-electronic-stability-control-esc-or-traction-control-sy.html)。

## 两个日夜按钮

底栏依次为统一日夜、地图日夜、主页，点击区互不重叠。

统一日夜按钮以仪表当前主题为基准，同时切换仪表和 iPhone CarPlay 地图，并清除地图独立模式。地图按钮仅改变 iPhone 地图/CarPlay 的日夜请求，不触发仪表配色动画，也不改变本地渐隐配色。iPhone 的日夜请求作用于 CarPlay 会话，因此返回完整 CarPlay 主屏后也会采用地图按钮选定的主题。

地图独立状态和仪表主题保存至本地，返回页面继续保持；重新选择统一模式时两者恢复一致。采用既有 nightModeController 与 AirPlay 日夜命令，不修改视频码流或创建另一连接。

## 渐隐与时长

顶部与右缘遮罩的最边缘 alpha 改为 255，使地图在边缘完全隐去并融入本地仪表底色。这里是地图画面可见度降至零，不是让覆盖层透明后再次露出下方视频。

本地仪表过渡默认 1000 ms。设置“融合仪表显示”新增 0～3 秒滑块，0.1 秒步进，可拖动或用方向键调节；0 秒立即切换。读取设置后下一次切换生效。iPhone 地图动画的持续时间无法由该本地设置保证，仍由源端实现决定。

## 用户验收与边缘修订

用户确认统一/地图独立切换、0～3 秒时长设置均正常。随后将顶部及右侧渐隐范围缩至前版 2/3：顶部 140→93.33、右侧 170→113.33 逻辑像素；原背景顶部遮罩的透明终点也同步缩至 2/3，避免叠加后仍出现较宽遮罩。

两处新增遮罩由线性 alpha 改为 33 个采样点的五次 smoothstep 曲线，函数为 t³(10−15t+6t²)，端点的一阶、二阶变化均平缓；最边缘保持完全隐藏地图。此处调整空间透明度分布，不改变已验收的日夜时间动画。iOS 的视觉可能还涉及材质模糊、色彩空间与背景对比，单张截图无法确认其内部算法，本轮不宣称完全复刻 iOS 材质。

纠正图标方向：TCS 改为圆形 TC 指示符，不再绘制汽车造型；能量回收改为电池、闪电及双向循环箭头，不再使用汽车轮廓。TC 不添加 OFF 或划斜线，避免把当前泛化状态接口画成“牵引力控制关闭”。图案为本地自绘，不宣称其为某厂家完整认证标志。参考：[GM 官方手册中的 TC 关闭标志与语义](https://contentdelivery.ext.gm.com/content/dam/cope/en_us/public/pdf_assets/active/owners_manuals_browse/2k12regal1011-2040436535645463004.pdf)。

本次边缘/图标修订已构建、认证资源校验并安装到红米。实机截图确认圆形 TC、电池回收符号、收窄渐隐和独立地图主题正常呈现。本轮未新增低影响图案单元测试，统一/独立主题及时长的 12 项相关测试已在前一步通过，并由用户验收。参考苹果材质说明：https://developer.apple.com/design/human-interface-guidelines/materials 。
