# 公开项目与私有参考图标边界

2026-10-14。按用户要求，原始参考项目图标及包含原图的对照资料不进入 DiPlay-Phone；已修改、自绘的 Canvas 图标可以随本项目公开。

原图对照图片和逐项审核文档已移到仓库之外的 DiPlay-local-support 私有参考目录。公开 README 不再链接私有审核资料。参考图案绘制、版式和状态接口均不依赖私有 PNG，构建 APK 不需要这些私有资料。

检查了 105 个原始参考图片的内容哈希及 Git blob ID，在本项目当前图片文件和可达 Git 历史中没有发现原图副本；包含原图的对照资料也没有提交记录。本次无需重写 Git 历史。

.gitignore 排除原图惯用文件名前缀及旧对照目录；scripts/check_public_tree.py 对已跟踪及未忽略的新文件检查私有参考路径，防止强制加入这些文件后漏检。新名称、截图拼贴等仍需审查内容，该检查不等同于自动识别所有图片。
