# 装车反馈后的显示调整

2026-10-15，Android Debug 3（versionCode 32），仍兼容 ESP32 v0.1.8，本轮无需更新 ESP32。

## 估算续航

协议没有真实续航字段。有效电量百分比 × 0.85，四舍五入为整数公里，明确标为“估算续航”；例如 80% → 68 km。它只是用户指定的简易系数，不是实车剩余里程、路线或电耗预测。电量无效时仍显示未知，不填入假估算。

## 低延迟显示缓冲

BLE 遥测维持 20 Hz；仪表显示使用 Choreographer 跟随 VSync，并以目标 60 Hz 调度。每个显示帧读取最新车辆快照，只在快照变化时重建数据；音乐、时间等仍约 20 Hz 更新。页面隐藏或解绑时撤销帧回调。

速度只在显示侧做 45 ms 的有界线性过渡，功率圈为 60 ms；不排队历史数据、不做多包平均、不预测未来速度。相同目标值不重启动画，新目标立即接管当前显示。停车归零、未知数据和演示/车辆模式切换立即响应。回收/驱动换向先清除旧方向圆弧，再绘制新方向。

60 Hz 是显示动画目标，不是 BLE 采样率，也不保证整数速度每秒变化 60 次。传感器数值未变时数字保持不变。功率数值、挡位和指示灯保留即时状态；只平滑功率圆弧及速度显示。设备实测帧率、绘制成本与验证条件另行记录。

## 指示灯与挡位

指示灯描边从 3 加到 4.5 个逻辑像素，READY/ABS/TC 等文字加粗；维修图标等局部粗线同步调整，不改变告警状态或闪烁逻辑。

挡位线值不变：0=P（黄）、1=ECO（绿）、2=S（橙）、3=T（红）、4=FREE（蓝）；A 覆盖显示白色。FREE 不再误标为推行。颜色对应板端 RGB565 定义，A 按本次用户要求为白色。

36 项定向回归通过，涵盖有界缓冲、重复数据、即时归零/无效值、正负功率切换、不同刷新率调度、续航、挡位及既有协议/布局。完整测试套件未重跑。

## 本机验证

最终包已覆盖安装到 Redmi K30 5G / Android 13，保留包名、签名和用户设置。实际界面可见 CarPlay 地图与 BLE 车辆数据；67% 电量对应估算 57 km，S 挡为橙色，指示灯描边与布局检查正常。A/ECO/FREE 等映射由定向测试验证，未在本轮逐一切换实车挡位验收。

前后台切换后统计：第一个 5 秒窗口 59.4 FPS，后续连续 5 秒窗口为 59.8～59.9 FPS。Canvas 命令记录平均约 1.8 ms，各窗口平均 1.32～2.06 ms，最大单次记录 12.24 ms。系统 gfxinfo 最近 120 帧的渲染速率为 59.86 FPS、帧间隔中位数 16.7 ms；本次重置后的 4229 帧中 jank 为 2.58%，漏 VSync 1 次。绘制记录时间不是 GPU 完整呈现耗时。

隐藏时停止帧回调并清空统计窗口，返回后重新采样且立即对齐当前数据。采集结束已关闭临时 DiPlayRender 调试日志。以上是本机短时数据，不能视为所有设备、CarPlay 地图视频或外置镜像屏的稳定 60 FPS 保证；本轮没有新增车辆传感器精度、长时间装车或强光环境验收。

36 项定向测试、mobile lint（18 个警告，无错误）、standalone debug 构建及 APK 签名、认证资源检查通过。截图和原始性能日志仅保存在本机支持目录，不进入公开仓库。
