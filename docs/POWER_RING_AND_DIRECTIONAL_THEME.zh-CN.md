# 功率圆弧与分方向日夜过渡

更新：2026-10-15。

## 功率圆弧

原速度数字外侧圆弧此前固定为 126°，未绑定实时值。本轮保留圆弧位置、半径、线宽、起点、260° 总行程及数字布局，将其明确用作功率圈，不用速度驱动，也不采用中间零点的双向能量条。

量程核对参考仪表当前源码，实际为驱动 +1400 W、回收 −600 W，并非记忆中的 +1500 W：

| 状态 | 输入范围 | 圆弧 | 色彩 |
|---|---|---|---|
| 驱动 | 0 → +1.4 kW | 0 → 100% | 原蓝色渐变 |
| 能量回收 | 0 → −0.6 kW | 0 → 100% | 绿色渐变 |
| 无效、未知 | 无可用功率 | 不显示活动圆弧 | 保留底轨 |

两个状态均从同一原有起点增长，超过量程钳制到 100%，不会绕圈或反向绘制。内外细线也随功率同步变色和增长。功率圈直接读取未格式化的数值，优先使用有效电压 × 电流计算结果，兼容旧固件功率。速度数字继续独立显示车速。

例如 +0.7 kW 为蓝色 50%，−0.3 kW 为绿色 50%；ESP32 当前演示 +1.2012 kW 约为蓝色 85.8%，−1.2012 kW 为绿色满格。DiPlay 自身默认演示 2.6 kW 超量程，显示蓝色满格，不调整演示数字。

仅核对参考工程的量程常量和数值逻辑，未复制其图片或私有图标。

## 分方向仪表过渡

设置 → 融合仪表显示提供两个 0～3 秒滑条，步进 0.1 秒：

- 夜间 → 日间：默认 1.2 秒。
- 日间 → 夜间：默认 1.6 秒。

两项分别保存，0 秒立即切换；下一次切换读取目标主题对应的时长。旧的单一 `transition_ms` 不再用于本轮方向设置，两项新设置从上述默认值开始。

统一日夜按钮仍同时请求仪表和 CarPlay 切换；地图独立按钮仍不影响仪表。滑条只控制本地仪表配色动画，iPhone 地图动画由源端执行，其真实时长可能随 iOS 或地图应用变化，因此可以分别微调以配合观感。

## 验证结果

- 构建和认证资源校验通过，新版已覆盖安装到 Redmi K30 5G。
- 27 项定向测试通过：功率圈 5 项、分方向主题 3 项、车辆协议 9 项、BLE 分片/超时 3 项、既有布局/主题 7 项。
- 实机同时显示 CarPlay 地图和 ESP32 演示数据，已分别抓取 +1.20 kW 蓝色约 85.8%、−1.20 kW 绿色满格画面；布局和地图保持正常。
- 两个方向的本地 ValueAnimator 时长选择由测试验证，实际与 iPhone 地图动画的同步观感仍需用户试用微调。当前未接实车。
- 私有参考图标未复制，截图保存在项目外的本机支持目录。
