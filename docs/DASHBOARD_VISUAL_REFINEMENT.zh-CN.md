# 六寸仪表视觉精修试版

2026-10-14。修改前归档版本为 7dd7d6f。本轮为用户确认后的视觉试版，不变更连接协议及车辆数据来源。

## 视觉调整

- 表盘与地图之间使用横向短过渡加椭圆径向遮罩：地图 TextureView 左缘保持遮盖，表盘轮廓外逐渐露出地图，减轻直线分界及长灰雾带。顶部与右侧仍保持已确认的 2/3 范围。
- 根据用户反馈，移除混合主题下约 11% 的地图压暗层；地图保留 iPhone 原始亮度，已有表盘融合、顶部/右缘及底部渐隐继续保留。
- 蓝色速度弧改为小幅深浅蓝色变化，内侧增加极细蓝色亮线；未增加发光、多圈装饰或文字粗描边。
- 底栏中文标签由 23 提高至 28 逻辑像素，960×480 输出约 14 像素；电量与续航数值提高至 40，约 20 像素；电压、电流、里程为 36，约 18 像素。
- 歌名 32、歌手 28，按实际可用宽度省略，不再仅按字符数量截断。音乐封面仍使用独立不透明画笔。
- 底栏加入轻微上下明度变化，圆角由 52 减为 32，弱化顶部/底部边框，保留圆润风格。
- 未激活图标降低夜间视觉权重；演示模式保留全部图案以便审核，非演示数据源下未激活的故障、ABS、TC、缓降、骑手未就座隐藏，槽位不移动，激活时恢复现有状态颜色。未新增实车连接，也不将未来状态源规则描述为已完成车辆协议测试。

## 保持的功能

2:1 物理居中、双向横屏、统一/独立地图日夜、0～3 秒时长设置、主副屏切换与主页均沿用现有实现。电量、电压、电流、功率等仍为演示数值。

未引入地图背景实时模糊，新增效果由本地 Canvas 渐变遮罩实现；私有参考位图继续位于 DiPlay-local-support，未复制进公开项目。

## 验证

7 项比例、双向横屏、独立地图主题、零时长和封面原色相关测试通过；APK 构建、认证资源校验、覆盖安装成功。用户连接 iPhone 后检查到真实地图与歌曲封面，截图确认夜间统一模式及日间仪表配夜间地图的布局，底栏加大后没有明显重叠。另按 2:1 内容区域缩到 960×480 检查静态小屏可读性；此预览不等同于车辆面板、压缩传输和实际视距验收。

自绘图标与源代码仍在公开仓库；所有实机截图保存在 DiPlay-local-support。本轮根据用户反馈移除地图额外压暗层，并以中文提交归档。

移除压暗层后的最终版本已重新构建、认证资源校验并覆盖安装成功；公开树检查与 git diff --check 通过。保留上一试版的 7 项相关测试结果，本次删除遮罩未新增或重跑单元测试。
